# Data Visualization — Global AI Jobs 2026

## Deskripsi Proyek
Proyek ini dibuat untuk memenuhi tugas mata kuliah Data Mining dengan topik **Data Visualization**. Dataset yang digunakan adalah **Global AI Jobs 2026** dari Kaggle, yang berisi informasi mengenai pekerjaan di bidang Artificial Intelligence (AI) dari berbagai negara dan industri.

Analisis dilakukan untuk memahami karakteristik pekerjaan AI berdasarkan spesialisasi, tingkat pengalaman, gaji, lokasi pekerjaan, serta ketersediaan sistem kerja dari rumah (*Work From Home*). Hasil analisis disajikan dalam bentuk visualisasi agar informasi lebih mudah dipahami.

## Dataset
Dataset Global AI Jobs 2026 memiliki **5.000 baris dan 37 kolom**. Data mencakup beberapa atribut, seperti jabatan pekerjaan, spesialisasi AI, industri, negara, tingkat pengalaman, gaji, keterampilan yang dibutuhkan, dan jenis sistem kerja.

Sumber dataset: [Kaggle — Global AI Jobs 2026](https://www.kaggle.com/datasets/datascikhan/global-ai-jobs-2026)

## Tahapan Pengerjaan
1. **Import Library**  
   Mengimpor library Python yang digunakan, yaitu Pandas, Matplotlib, dan Seaborn untuk pengolahan serta visualisasi data.

2. **Load Dataset**  
   Memuat dataset berformat CSV ke Google Colab untuk dilakukan analisis lebih lanjut.

3. **Data Exploration**  
   Memeriksa struktur dataset, jumlah baris dan kolom, tipe data, nilai kosong (*missing values*), serta data duplikat.

4. **Data Cleaning**  
   Melakukan pemeriksaan dan penyesuaian data agar dapat digunakan dalam proses analisis dan visualisasi.

5. **Data Visualization**  
   Membuat lima visualisasi untuk melihat pola dan karakteristik data, yaitu:
   - Distribusi jumlah catatan pekerjaan berdasarkan spesialisasi AI.
   - Perbandingan median gaji berdasarkan tingkat pengalaman.
   - Sepuluh negara dengan jumlah catatan pekerjaan terbanyak.
   - Perbandingan ketersediaan sistem kerja dari rumah (*Work From Home*).
   - Tren jumlah catatan pekerjaan berdasarkan tahun posting.

6. **Analisis dan Kesimpulan**  
   Menginterpretasikan hasil visualisasi untuk menemukan pola atau informasi yang menarik, serta memperhatikan keterbatasan dataset agar kesimpulan tidak ditafsirkan secara berlebihan.

## Tools dan Teknologi
- **Python** — bahasa pemrograman untuk analisis data.
- **Google Colab** — lingkungan untuk menjalankan kode Python.
- **Pandas** — pengolahan dan analisis data.
- **Matplotlib** — pembuatan grafik dan visualisasi.
- **Seaborn** — membantu penyajian visualisasi data.

## Tujuan
Melalui proyek ini, diharapkan dapat diperoleh pemahaman mengenai karakteristik data pekerjaan di bidang AI serta kemampuan untuk mengolah, menganalisis, dan menyajikan data dalam bentuk visualisasi yang informatif dan mudah dipahami.
